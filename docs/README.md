# Speisekarte — цифровое меню с QR

Статическая страница меню: поиск по блюдам, категории, предложение дня,
сборка заказа с допродажей (гарнир / салат / соус / напиток) и отправкой
готового текста в WhatsApp или Telegram.

Адрес после включения GitHub Pages:
**https://barnaslav91-blip.github.io/poPromtu/**

## Что в папке

| Файл | Что это |
|---|---|
| `index.html` | само меню, весь код в одном файле |
| `manifest.webmanifest` | чтобы меню ставилось на главный экран как приложение |
| `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` | иконки для главного экрана |
| `qr-speisekarte.png`, `.svg` | QR-код на меню (SVG — для печати любого размера) |
| `karten-a4.html`, `karten-a4.pdf` | лист A4 с четырьмя карточками для раздачи |
| `spenden/index.html` | страница сбора денег с целью 1000 € (см. ниже) |

## Сайт уже включён

Публикация идёт автоматически через GitHub Actions (`.github/workflows/pages.yml`):
любое изменение внутри `docs/` в основной ветке пересобирает сайт примерно за минуту.
В **Settings → Pages** ничего менять не нужно — если переключить там источник на
*Deploy from a branch*, автоматическая публикация сломается.

Рядом, по адресу `/gazon/`, из этой же папки публикуется страница услуг покоса травы.

## Как вписать номер WhatsApp

Открыть `index.html`, найти в начале скрипта блок `CONTACT` и заполнить:

```js
const CONTACT = {
  whatsapp: "4915112345678",   // номер без + и без пробелов
  telegram: "meinimbiss",      // username без @
  channel: ""                  // ссылка на канал WhatsApp, если есть
};
```

Пустое поле просто прячет соответствующую кнопку. Если оба пустые —
клиент видит кнопку «Bestellung kopieren» и вставляет заказ сам.

## Как поменять цены

Всё меню лежит в `index.html` в массиве `MENU`. Одна строка — одно блюдо:

```js
[13, "Bauernschnitzel", "mit gebr. Zwiebeln, Speck, ...", ["6,30", "7,80", "6,30"]],
```

Это: номер, название, описание, цены `[klein, groß, Hähnchen]`.
Меняете число — сохраняете — цена обновилась у всех, кто откроет меню.

Предложения дня — в массиве `DAYS`, там же `dow` (день недели: 1 = понедельник).

## Что предлагается к блюду

Массив `ADDONS` задаёт наборы допродажи, а у каждого раздела меню поле
`addons` перечисляет, какие из них показывать. Например к бургерам
показываются картошка, соус и напиток, а к салатам — только напиток.

## Страница сбора денег (`spenden/`)

Отдельная страница на том же сайте: **`https://barnaslav91-blip.github.io/poPromtu/spenden/`**.
Показывает цель (по умолчанию 1000 €), сколько уже собрано, полосу прогресса,
даёт выбрать сумму и перейти к оплате — PayPal, ссылка на оплату картой,
перевод по IBAN с QR-кодом (Girocode) для банковского приложения. Внизу —
кнопки «поделиться» и QR-код самой страницы, который можно распечатать и
поставить на стойку.

Публикуется тем же workflow, что и меню, но он запускается только с ветки
`claude/youtube-moderation-links-ozxyoz` — пока страница не влита в неё, по
адресу выше её не будет. Локально файл открывается двойным кликом, без сервера.

Весь код в одном файле `spenden/index.html`, ничего снаружи не подгружается.
Настраиваются три блока в начале скрипта.

**1. `AKTION` — цель и текст:**

```js
const AKTION = {
  ziel:    1000,                       // цель в евро, просто число
  eyebrow: "Spendenaktion",            // надпись над заголовком
  titel:   "1.000 € für den Imbiss",   // заголовок
  zweck:   "Wir sammeln für …",        // на что собираем
  frist:   "",                         // "2026-12-31" или пусто (без срока)
  hinweis: "Private Sammlung ohne Gegenleistung. …"
};
```

**2. `ZAHLWEGE` — куда платить.** Пустое поле просто прячет свой способ оплаты:

```js
const ZAHLWEGE = {
  paypal: "meinimbiss",                       // имя в PayPal.me, без "paypal.me/"
  karte:  "https://buy.stripe.com/…",         // любая ссылка на оплату (Stripe, SumUp, GoFundMe)
  name:   "Imbiss & Grill Bernd Müller",      // владелец счёта — как в банке
  iban:   "DE02 1203 0000 0000 2020 51",      // с пробелами или без
  bic:    "",                                 // нужен только вне SEPA
  zweck:  "Spendenaktion"                     // назначение платежа, до 140 знаков
};
```

IBAN проверяется по контрольной сумме: если он введён с ошибкой, блок перевода
не показывается, а внизу страницы появляется подсказка для владельца. QR-код
перевода делается по стандарту EPC069-12 (Girocode) — тот же, что печатают на
счетах в Германии, — и содержит уже выбранную посетителем сумму.

**3. `EINGANG` — что уже собрано.** Одна строка — один взнос, сумма считается
сама, наличные вносятся так же:

```js
const EINGANG = [
  ["2026-08-12", 50,    "Familie Müller"],
  ["2026-08-13", 20.50, ""],                  // пустое имя показывается как "Anonym"
  ["2026-08-14", 129.50, "Barspenden Tresen"] // наличные из кассы
];
```

Строка добавлена — сохранили — у всех обновился прогресс. Кнопки сумм
(5/10/20/50/100 €) меняются в массиве `BETRAEGE`.

Ссылку на сбор можно поставить в меню: в `index.html` рядом с кнопкой канала
WhatsApp добавить `<a class="btn-ghost" href="spenden/">Spendenaktion</a>`.

**О чём стоит подумать до запуска:** сбор денег от имени заведения — это доход
или частное дарение в зависимости от того, как оформлено; страница честно пишет,
что квитанцию (Spendenquittung) выдать нельзя. Если сбор идёт на конкретную
покупку, текст `AKTION.hinweis` лучше согласовать со своим налоговым
консультантом.

## Важно

Адрес QR-кода зашит в напечатанные карточки. Если меню переедет на свой
домен, QR придётся перегенерировать и перепечатать. Поэтому перед большим
тиражом лучше сразу взять домен и вести QR на него.
