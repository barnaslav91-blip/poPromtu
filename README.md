# poPromtu

В репозитории живут два независимых приложения на одном Express-сервере:

- **«Рядом»** (`/ryadom`) — встречи с людьми поблизости: выпить кофе, сходить в бар,
  погулять. Описание ниже.
- **Модерация видео** (`/admin`, `/moderate/:slug`) — инструмент для правок к видео
  перед загрузкой на YouTube.

---

# «Рядом» — с кем выпить кофе и погулять

Люди рядом пишут, куда и когда идут (бар, прогулка, кофе, спорт), остальные видят
эти встречи в ленте с расстоянием до места и присоединяются. Вход — `/ryadom`.

## Как это работает

- **Без регистрации.** Гость вводит имя, профиль привязывается к браузеру
  (кука на полгода + серверная сессия). Телефон и почта не нужны.
- **Геолокация по кнопке.** Координаты запрашиваются только после явного согласия
  и хранятся у профиля, чтобы считать расстояния.
- **Лента встреч** с фильтрами по занятию и радиусу (1 / 3 / 10 / 50 км / везде),
  отсортирована по времени начала. Встреча висит в ленте ещё 2 часа после старта,
  чтобы опоздавшие успели дойти.
- **Своя встреча:** занятие, место словами, время (есть кнопки «через 30 мин»,
  «через час», «сегодня в 19:00»), лимит людей (2–12) и детали.
- **Страница встречи:** кто идёт, чат для участников, «я иду» / «я передумал(а)»,
  отмена встречи организатором.
- **Безопасность:** точные координаты никому не показываются — только округлённое
  расстояние («меньше 300 м», «1,2 км»); есть жалоба на встречу, после которой она
  пропадает из ленты пожаловавшегося, а запись остаётся для модерации.

## Что стоит доделать перед реальными пользователями

- Постоянное хранилище сессий (сейчас `MemoryStore`; профиль восстанавливается из
  куки, но корзина сессий теряется при рестарте).
- Модерация жалоб в админке и блокировка авторов.
- Пуш/почта о новых встречах рядом и сообщениях в чате.
- Фильтрация по радиусу считается в приложении (лента ограничена 200 ближайшими по
  времени встречами) — при росте города понадобится индекс PostGIS или bounding box в SQL.

# Модерация видео

Инструмент для модерации видео перед загрузкой на YouTube: вставляете ссылку на видео,
получаете уникальную ссылку на модерацию, команда проверяющих (2 и больше) оставляет
правки с привязкой к таймкоду, вы видите их все в одном месте и отмечаете исправленные.

## Возможности

- Админка (закрыта паролем): добавление видео по ссылке/ID YouTube, генерация
  уникальной ссылки на модерацию, управление командой проверяющих.
- Страница модерации: встроенный YouTube-плеер, кнопка «взять текущее время видео»,
  выбор проверяющего из фиксированного списка, список всех оставленных правок.
- В админке — список правок по видео с отметкой «исправлено» / «вернуть в открытые».

## Запуск локально

Нужен Postgres (локально или в контейнере).

```bash
npm install
cp .env.example .env   # задайте ADMIN_PASSWORD, SESSION_SECRET и DATABASE_URL
npm start
```

Приложение поднимется на `http://localhost:3000`: «Рядом» — `/ryadom`,
админка модерации — `/admin`. Таблицы в базе создаются автоматически при старте.

Геолокация в браузерах работает только на `localhost` или по HTTPS — на боевом
домене без сертификата лента «что рядом» не сможет определить место.

## Деплой на Render

В репозитории есть `render.yaml` — Render Blueprint, который сразу создаёт
веб-сервис и базу Postgres.

1. Запушьте репозиторий в GitHub (уже сделано).
2. На [render.com](https://render.com) → **New** → **Blueprint** → выберите
   этот репозиторий.
3. Render прочитает `render.yaml` и предложит создать:
   - веб-сервис `popromtu` (Node, free-план);
   - базу `popromtu-db` (Postgres, free-план), автоматически подключенную
     через переменную `DATABASE_URL`.
4. Перед деплоем Render попросит задать `ADMIN_PASSWORD` вручную (он не
   хранится в репозитории) — введите пароль для входа в `/admin`.
   `SESSION_SECRET` Render сгенерирует сам.
5. Нажмите **Apply** — через пару минут сервис будет доступен по адресу
   вида `https://popromtu.onrender.com`.

**Важно про free-план Render:**
- Бесплатный веб-сервис засыпает после ~15 минут без запросов и просыпается
  10–30 секунд при первом обращении — для внутреннего инструмента это обычно
  не критично.
- Бесплатная база Postgres на Render **удаляется через 30 дней**, если не
  перейти на платный план — для долгосрочного использования базу нужно будет
  апгрейднуть (Render заранее присылает предупреждение на почту).

Если Blueprint недоступен (например, региональные ограничения), сервис можно
создать вручную: **New → Web Service** из репозитория (Build command
`npm install`, Start command `npm start`) и **New → PostgreSQL**, а затем
вручную прописать `DATABASE_URL`, `ADMIN_PASSWORD`, `SESSION_SECRET` в Environment
веб-сервиса.

## Как пользоваться

1. Зайдите в `/admin`, добавьте в команду проверяющих (имена).
2. Вставьте ссылку на YouTube-видео и название — получите ссылку вида
   `/moderate/<slug>`.
3. Отправьте эту ссылку проверяющим — они выбирают своё имя из списка,
   ставят таймкод и пишут правку.
4. В админке на странице видео отмечайте правки исправленными по мере
   доработки видео.
