# Шрифты для PDF

`DejaVuSans.ttf` и `DejaVuSans-Bold.ttf` встроены в PDF-выгрузки: без
встроенного шрифта PDF не умеет показывать кириллицу, а стандартные шрифты
PDF (Helvetica и прочие) её не содержат.

DejaVu выбран потому, что покрывает и кириллицу, и румынские диакритики
(ș, ț, ă, î, â) — объявления и заявки бывают на обоих языках.

Лицензия — в `LICENSE-DejaVu.txt` (свободная, основана на Bitstream Vera).
