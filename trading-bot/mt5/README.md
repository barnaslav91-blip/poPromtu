# CrashTrendEA — советник для Deriv MT5

Порт логики из `trading-bot/src` (Node.js/Deriv API) на MQL5 — для тех, кто
торгует через **Deriv MT5** (терминал MetaTrader 5), а не через Deriv API
напрямую. Если вы используете `DERIV_API_TOKEN`/DTrader — вам нужен
Node-бот в `trading-bot/src`, а не этот файл.

Стратегия та же: EMA-тренд + доля растущих/падающих тиков задают
направление (long/short), стохастик подтверждает вход, ATR определяет
жёсткий стоп и трейлинг (chandelier exit через `PositionModify`), риск на
сделку — фиксированный % баланса без мартингейла, дневной лимит убытка.

## Важно про то, где это работает

Советник исполняется **внутри запущенного терминала MT5 на компьютере**,
к графику которого он прикреплён. Он не работает "из мобильного" —
телефон только показывает счёт, а торгует десктопный терминал (или VPS,
если арендуете его у брокера для круглосуточной работы). Если закрыть
терминал на компьютере — советник перестаёт торговать.

**Я не могу скомпилировать и запустить этот файл вместо вас** — MetaEditor
(компилятор MQL5) есть только внутри самого MT5, у меня в этой сессии его
нет. Если при компиляции будут ошибки — пришлите текст ошибки, поправлю.

## Установка

1. В MT5: **Файл → Открыть каталог данных** → `MQL5/Experts/`.
2. Скопируйте туда `CrashTrendEA.mq5` (или откройте MetaEditor: `Файл →
   Новый → Советник`, вставьте содержимое файла).
3. В MetaEditor нажмите **Compile** (F7). Должно быть "0 errors, 0
   warnings" в консоли внизу.
4. В MT5 откройте график нужного инструмента — **Crash 900 Index** (или
   Crash 1000, если торгуете им — символ отдельно указывать не нужно,
   советник торгует тем графиком, к которому прикреплён).
5. В "Навигаторе" (Ctrl+N) найдите `CrashTrendEA` в разделе Советники,
   перетащите на график.
6. В открывшемся окне настроек — вкладка **Общие**: включите "Разрешить
   торговлю по алгоритму". На вкладке **Входные параметры** — при желании
   поменяйте риск/пороги (по умолчанию совпадают с Node-версией).
7. Убедитесь, что кнопка **AutoTrading** в верхней панели MT5 включена
   (зелёная, не красная).
8. На графике должен появиться значок советника (улыбка в углу графика) —
   значит, он запущен и ждёт тиков.

## Параметры (соответствуют `.env` из Node-версии)

| MQL5 input | .env аналог | По умолчанию |
|---|---|---|
| `RiskPerTradePct` | `RISK_PER_TRADE_PCT` | 1.0 |
| `MaxDailyLossPct` | `MAX_DAILY_LOSS_PCT` | 5.0 |
| `StopAtrMultiple` | (в коде strategy.js) | 1.5 |
| `TrailAtrMultiple` | `TRAIL_ATR_MULTIPLE` | 2.5 |
| `CooldownTicksAfterCrash` | `COOLDOWN_TICKS_AFTER_CRASH` | 20 |
| `StochPeriod/SmoothK/SmoothD/Overbought/Oversold` | `STOCH_*` | 14/3/3/80/20 |
| `TickDirectionWindow/UpThreshold/DownThreshold` | `TICK_DIRECTION_*` | 200/0.55/0.45 |

## Отличия от Node-версии (важно понимать)

- **Символ** берётся с графика (`_Symbol`), а не резолвится по
  display_name — просто прикрепите советник к правильному графику.
- **Трейлинг** двигает реальный SL позиции у брокера (`PositionModify`),
  а не закрывает позицию вручную по тику, как в Node-версии — надёжнее
  при обрывах связи.
- **Лот** считается из `SYMBOL_TRADE_TICK_VALUE`/`SYMBOL_TRADE_TICK_SIZE`
  символа и округляется до шага объёма брокера — сумма риска в валюте
  счёта эквивалентна Node-версии, но точный лот зависит от параметров
  контракта у вашего брокера.
- **Бэктест/калибровка** (`npm run backtest`, `npm run calibrate`) остаются
  только в Node-версии — параметры, подобранные там, переносите сюда
  вручную через input-поля. Полноценный тест этой EA-логики — через
  **Strategy Tester** в самом MT5 (Ctrl+R), на тиковых данных Crash 900
  Index за нужный период.

## Демо перед реальным счётом

Прикрепляйте советника сначала к демо-счёту (как на вашем скриншоте —
`Deriv-Demo`). Реальный счёт — осознанный отдельный шаг, после того как
устроят результаты на демо.
