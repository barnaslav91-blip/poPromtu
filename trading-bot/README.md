# trading-bot

Бот для торговли синтетическим индексом **Crash 900 Index** на [Deriv](https://deriv.com).
Отдельный проект внутри репозитория `poPromtu`, со своими зависимостями —
на основное Express-приложение никак не влияет.

## Как устроена стратегия

Момент "краха" на Crash-индексах — случайное событие с фиксированной
вероятностью на тик, предсказать его нельзя (так задуман инструмент).
Поэтому бот не пытается угадать крах, а:

1. Торгует только по восходящему дрейфу цены (EMA9 > EMA21 на минутных
   свечах, построенных из тиков) — между крахами индекс в среднем растёт.
2. Адаптирует размер стоп-лосса под текущую волатильность (ATR): шире стоп
   в неспокойном рынке, уже — в спокойном.
3. После обнаружения резкого падения тика (крах-событие) ставит паузу на
   `COOLDOWN_TICKS_AFTER_CRASH` тиков — не открывает новые позиции, пока
   цена не стабилизируется.
4. Считает размер сделки как фиксированный % риска от баланса
   (`RISK_PER_TRADE_PCT`) — **без мартингейла**, ставка не растёт после
   проигрышей. Именно удвоение ставки после убытка — типичная причина
   слива депозита на этом инструменте.
5. Останавливает торговлю на день при достижении `MAX_DAILY_LOSS_PCT`.

Торгуются мультипликаторные контракты (MULTUP) с жёстким `stop_loss`,
выставленным на бирже — риск на сделку известен заранее и не зависит от
скорости реакции бота.

**Это не гарантия прибыли.** У синтетических индексов Deriv встроенное
преимущество площадки (house edge). Стратегия управляет риском и ловит
тренд, а не "обыгрывает" площадку.

## Настройка

Нужен аккаунт на [deriv.com](https://deriv.com) (подойдёт бесплатный) и:

1. `DERIV_APP_ID` — зарегистрируйте приложение на
   https://api.deriv.com/dashboard/ (Register application), возьмите App ID.
2. `DERIV_API_TOKEN` — Settings → API token на deriv.com. **Для старта
   создайте токен на демо-счёте** (переключитесь на демо в верхнем меню
   перед созданием токена) со скоупами `Read` и `Trade`.

```bash
cd trading-bot
npm install
cp .env.example .env   # впишите DERIV_APP_ID и DERIV_API_TOKEN
```

## Бэктест (сделать перед демо-торговлей)

Прогоняет стратегию на исторических тиках без реального счёта и без
токена (нужен только `DERIV_APP_ID`):

```bash
npm run backtest
```

Выведет число сделок, win rate, итоговый P&L и максимальную просадку на
виртуальном балансе 1000. Если просадка/статистика выглядят плохо —
меняйте параметры в `.env` (`RISK_PER_TRADE_PCT`,
`COOLDOWN_TICKS_AFTER_CRASH`) или пороги в `src/strategy.js` перед тем,
как переходить к демо-счёту.

## Демо-торговля

```bash
npm start
```

Бот подключится к Deriv, подпишется на тики Crash 900 Index и начнёт
торговать на счёте, привязанном к `DERIV_API_TOKEN`. Все сделки пишутся
в консоль и в `trades.log` (JSON lines). Остановить — `Ctrl+C`.

Убедитесь, что токен выпущен именно для **демо-счёта** — с реальным
токеном бот сразу начнёт торговать настоящими деньгами.

## Переход на реальный счёт

Осознанный отдельный шаг: создайте API-токен на реальном счёте и
подставьте в `.env`. Рекомендуется сначала не меньше нескольких недель
понаблюдать за демо-результатами и при необходимости снизить
`RISK_PER_TRADE_PCT`.
